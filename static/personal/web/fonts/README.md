# Adventor Todo

The board's default typeface. It is a modified version of [TeX Gyre Adventor](https://www.gust.org.pl/projects/e-foundry/tex-gyre/adventor) 2.501 by B. Jackowski, J. M. Nowacki et al., distributed under the [GUST Font License](GUST-FONT-LICENSE.txt), which is legally the LaTeX Project Public License 1.3c or later ([LPPL-1.3c.txt](LPPL-1.3c.txt)).

Changes from the original, reproduced by `dev/make-font.py`:

- subset to 473 characters: Basic Latin, Latin-1, Latin Extended-A, Greek, common punctuation, arrows and math symbols
- vertical metrics changed so that line boxes keep the height the layout was designed with
- renamed from "TeX Gyre Adventor" to "Adventor Todo", file names and internal names alike, as the license asks of modified versions

The unmodified fonts are on CTAN: https://www.ctan.org/pkg/tex-gyre-adventor

The authors of TeX Gyre Adventor do not support this modified version.
